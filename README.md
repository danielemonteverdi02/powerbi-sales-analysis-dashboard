# 📈 Sales Analysis Dashboard

## 📌 Project Overview
This project is an interactive Power BI dashboard focused on sales performance analysis.

The dashboard was created to simulate a real business reporting environment and provide insights into:
- sales performance,
- return rates,
- product performance,
- regional sales distribution,
- payment methods,
- salesperson performance.

The objective of the project was to practice Power BI development and business-oriented data visualization.

---

# 📊 Dashboard Features

## KPI Cards
The top section contains the main business KPIs:
- Total Sales
- Discount Rate
- Total Orders
- Return Rate
- Average Order Value

Each KPI includes a trend sparkline to provide a quick overview of performance changes over time.

---

## Sales Trend Analysis
A time-series chart compares:
- Total Orders
- Total Returned Orders

This helps identify:
- seasonal patterns,
- order fluctuations,
- return trends over time.

---

## Regional Sales Analysis
A horizontal bar chart displays total sales by region:
- North America
- Asia
- Europe
- Africa
- South America

This allows quick comparison between geographical markets.

---

## Product Performance
A product ranking chart highlights top-selling products based on total sales.

This section helps identify:
- best-performing products,
- weaker products,
- sales concentration.

---

## Payment Method Analysis
A donut chart shows sales distribution across payment methods:
- Online
- Credit Card
- Cash
- Gift Card
- Debit Card

---

## Salesperson Performance
A detailed table provides:
- salesperson names,
- total sales,
- total orders.

This allows performance comparison across team members.

---

## Interactive Filters
The dashboard includes multiple slicers:
- Region
- Product
- Payment Method
- Store Location
- Salesperson
- Date Range

These filters enable dynamic and customized analysis.
